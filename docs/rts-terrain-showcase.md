# RTS Terrain Showcase

The showcase borrows the readability grammar of classic RTS terrain editors without reproducing StarCraft II assets: broad playable plateaus, cliff separation, a readable ramp, path material, basin/water focal area and clustered semantic dressing.

The visual target remains Aetherius Artistic PBR v2. Physical terrain is the stable source; final mode compresses detail and remaps material/light response into authored color masses.

Controls:
- Q / E: zoom
- Space: toggle FINAL / PHYSICAL interpretation
- R: regenerate terrain/scatter seed

This is a showcase vertical slice, not the final terrain editor.
